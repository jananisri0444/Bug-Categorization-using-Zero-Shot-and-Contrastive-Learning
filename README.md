# Bug-Categorization-using-Zero-Shot-and-Contrastive-Learning
As software becomes more intricate, it is a burgeoning challenge to deal with and close bug reports effectively. Proper categorization does not allow the developer to put emphasis on problems of importance first, causing fixation delay and escalating the cost of maintenance. Automating bug classification improves this practice through similar clustering of issues, better triaging, and the ability to hasten debugging.

This work introduces a new framework for classifying bugs with minimal reliance on annotated data utilizing Zero-Shot Learning (ZSL). Google T5 is utilized for labeling unstructured bug reports for the first time. SBERT embeddings are retrieved from the labeled dataset and optimized through Contrastive Learning within a Siamese Network to further improve classification accuracy. The optimized embeddings are then employed to classify new bug reports into five predefined classes by a Multi-Layer Perceptron (MLP) classifier.

Early attempts were through the experimentation of different encoding and classification techniques. Conventional models needed a huge amount of labeled data, but the new technique utilizes ZSL and SBERT-based embeddings for increased adaptability and minimizing the overhead of labeling. Improvements were further obtained by contrastively learning embeddings in order to increase the accuracy of the classifier. The technique immensely improves the performance of large-scale bug tracking systems by minimizing effort and maximizing the precision of classification.
